Stable Version
Version 2.20.21

new architecture of Modules
Modules:
    localization: 
        - localization node
    perception: 
        - traffic light handler node
        - object detection handler node
    planning: 
        - Mission planning node: publishes the path form start to dest
        - behavior path planning: determining the lookahead point and speed of the vehicle
        - behavior motion planning: handles planning according to traffic light and collision avoidance. determine th estop point and status
    control: 
        - control node using PID and Pure pursuit
    system:
        Portal:
            - Detects sudden jump in the vehicle position
            - Reports whether the vehicle teleported or not
            - reports whether the vehicle has teleported the specified times or not 
            - Repeat count can be modified in the scenario_config file.
        Sim_monitor:
            - Monitors the clock comming from the simulator and calculates lag between system and simulator
            - Reports system time, simulator time and lag between them.
    common:
        - stores maps and config files and generally all the common files that the modules may use
    simple_av:
        - One Package to launch them All!
